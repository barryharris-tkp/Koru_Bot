# Koru_Bot

Assistant for ERP systems.

Koru_Bot is planned as an autonomous personal assistant agent. The goal is for it to run with its own computer environment (a VM with a browser) so it can carry out multi-step work on its own, and to keep persistent memory so context carries over between sessions.

## Status

Early stage. This repository is a starting point and no components are built yet.

## Planned capabilities

- Its own workspace: a dedicated VM and browser the agent operates in, kept separate from the user's machine.
- Persistent memory: facts, preferences, and task history that survive across sessions.
- ERP assistance: helping with work inside ERP systems.
- Human approval: the agent asks before actions that cannot be undone.
